MarkVault Clipper Privacy Policy

Last updated: August 18, 2026

MarkVault Clipper is a browser extension for clipping web pages or selected text into Markdown and sending the result to a user-configured, self-hosted MarkVault Clipper server.

Data the extension accesses

When you actively use the extension to clip a page, MarkVault Clipper may access:

  • The current tab URL and page title.
  • The readable article content or selected text from the current page.
  • Image and resource URLs from the clipped page when resource downloading is enabled.
  • Extension settings that you enter, such as server URL, token, vault name, clip folder, assets folder, tags, and language preference.

How data is used

The accessed data is used only to create Markdown clips, preview Markdown, download Markdown locally, or send Markdown and optional resources to the MarkVault Clipper server that you configure.

Data sharing

MarkVault Clipper does not sell, rent, or transfer user data to third parties. The extension sends clipping data only to the server URL configured by the user.

Remote code

MarkVault Clipper does not execute remote code. The extension runs packaged code from the installed extension.

Storage

Extension settings are stored locally in the browser extension storage. Clipped Markdown and downloaded resources are stored in the user's configured vault through the self-hosted server, or downloaded locally by the browser when the user chooses local Markdown download.

User control

Users control the server URL, token, target vault, clip folder, assets folder, tags, and whether resources are downloaded. Users can remove stored extension settings by clearing the extension data or uninstalling the extension.

Contact

For privacy questions or support, open an issue at https://github.com/isredjiang/markvault-clipper/issues.
