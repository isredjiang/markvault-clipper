MarkVault Clipper

打开网页，点一下扩展，就能把正文整理成 Markdown。可以直接下载，也可以发到你自己部署的服务端，保存到指定的笔记库。

Turn web pages into Markdown in the browser, download them locally, or send them to your own backend and save them into a chosen vault.

网页文章

A web article

正文、标题、链接和图片会被整理成更适合保存的 Markdown。

Body, title, links, and images are cleaned up into Markdown that is easier to keep.

剪下来的是 Markdown，不是网页残片。

Clip once, keep a note you can still edit.

扩展负责提取正文、转格式；服务端只按你填的库名和路径保存文件。以后换 Obsidian、Ignis 或别的 Markdown 工具，文件还在自己手里。

The extension extracts and converts content in the browser. The backend only writes the result to the vault and folders you choose.

R

提取正文

Readable extraction

用 Readability 尽量抓文章主体，少带导航、广告、推荐栏这些杂项。

Uses Mozilla Readability to reduce navigation, ads, and sidebar noise.

M

转成 Markdown

Markdown conversion

标题、链接、列表、代码块、表格尽量保留下来，方便后面继续编辑。

Powered by Turndown and GFM for headings, links, lists, code, and tables.

V

选择笔记库

Multi-vault writes

在扩展里填写库名；服务端只接受已配置的库，避免文件写到奇怪的位置。

Choose the vault in the popup. The server rejects missing vaults.

A

保存图片

Local assets

需要时把页面图片下载到资源目录，并把正文里的图片链接改成本地路径。

Optionally downloads page images and rewrites links to local vault paths.

T

保存常用配置

Saved templates

常用的库名、剪藏路径、资源路径和标签可以保存成模板，少重复填写。

Save vault, folders, tags, and clipping preferences for repeated use.

D

直接下载

Local download

不想写入服务端时，也能直接下载 Markdown 文件，先看看转换结果。

Download Markdown directly from the browser without using the server.

扩展做转换，服务端只管保存。

The browser converts. The server saves.

网页解析放在浏览器里完成，后端不用处理复杂页面，也不用跑一堆额外服务。它收到 Markdown 后，只负责创建文件夹、保存笔记和下载图片。

The backend does not parse pages or run a heavy clipping engine. It receives the clip and writes it to the right place.

01

打开文章

Open page

在 Edge 或 Chrome 打开要保存的网页。

Open the article in Edge or Chrome.

02

扩展转换

Convert Markdown

扩展在当前浏览器里提取正文，并生成 Markdown 预览。

The extension extracts content and converts it locally.

03

发送结果

Send to server

确认没问题后，把 Markdown、库名和路径发给你的后端。

Only final Markdown and destination settings are sent.

04

写进库里

Write vault

服务端创建缺失文件夹，保存笔记，并按需下载图片资源。

The server creates folders, saves notes, and downloads assets.

服务端用 Docker 跑起来就能用。

One Docker container is enough.

把服务端放在你的主机或 NAS 上，挂载笔记库目录，浏览器扩展填入 HTTPS 地址和令牌即可使用。

Run the backend on your host or NAS, mount your vaults, then point the extension to its HTTPS URL and token.

services:
  markvault-clipper:
    image: isredjiang/markvault-clipper:latest
    container_name: markvault-clipper
    environment:
      - MARKVAULT_TOKEN=change-this-token
    volumes:
      - /path/to/obsidian-vaults:/vaults
    ports:
      - "3217:3217"

默认示例会把 3217 端口暴露到宿主机所有网卡。公网部署时建议配合 HTTPS 反向代理、防火墙或访问控制使用。
